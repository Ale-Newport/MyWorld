# Licensed web fonts

Akzidenz-Grotesk Pro and Neue Montreal are commercial typefaces, so their files are not in the repository.
To use them, buy/download the web licence, convert to WOFF2 if needed, and save exactly:

```
public/fonts/akzidenz-grotesk-pro/Regular.woff2   (400)
public/fonts/akzidenz-grotesk-pro/Medium.woff2    (500)
public/fonts/akzidenz-grotesk-pro/Bold.woff2      (700)
public/fonts/neue-montreal/Regular.woff2          (400)
public/fonts/neue-montreal/Medium.woff2           (500)
public/fonts/neue-montreal/Bold.woff2             (700)
```

Then pick the typeface in `/admin/settings` → Appearance, save and publish. Until a family's files exist the site
shows Helvetica Neue for it. (Space Grotesk is bundled and needs nothing.)
